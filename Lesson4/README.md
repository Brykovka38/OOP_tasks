# Урок 4. Обработка событий

## Описание программы

Разработано приложение с графическим интерфейсом, демонстрирующее обработку трёх видов событий.

### 1. Выбор языка программирования — JComboBox

Пользователь может выбрать один из трёх языков программирования:

- Java
- C#
- Python

При изменении выбранного элемента автоматически обновляется надпись с названием языка.

### 2. Отображение информации — JCheckBox

Флажок «Показывать информацию о языке» позволяет отображать или скрывать описание выбранного языка.

Если флажок установлен, при переключении языка описание также обновляется.

### 3. Анализ введённой строки — JTextField

Пользователь вводит текст в поле, а программа автоматически определяет количество символов и характеристику строки.

| Длина строки | Характеристика |
|---|---|
| 0–5 символов | Короткая |
| 6–10 символов | Нормальная |
| Более 10 символов | Длинная |

Результаты обновляются при добавлении и удалении символов.

## Структура проекта

```text
Lesson4/
├── Main.java
├── EventWindow.java
```

**EventWindow.java** — класс графического окна, содержащий компоненты интерфейса и обработчики событий.
